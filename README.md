Datamon Answer Checker — Web Interface (Streamlit prototype)
What this is
A lightweight Streamlit web UI to let authorized users validate Datamon answers from a browser. This repository is a rapid prototype (vibe coding) intended to integrate your existing Datamon checking logic into a simple UI.

Included:

app.py — Streamlit app (UI + placeholder checker)
FRAMEWORK_DECISION.md — reasoning for choosing Streamlit
ITERATION_LOG.md — iteration log and example prompts
How to install (local)
Make a Python 3.9+ venv:
python -m venv .venv
source .venv/bin/activate  # or .venv\Scripts\activate on Windows
